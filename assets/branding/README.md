# Marca

**Teams Facultad MCP · Tu cursada, conectada.**

Identidad editorial inspirada en un boletín universitario: papel cálido, tinta
verde oscura, un acento terracota y una serif para el título. El símbolo une una
espina vertical y tres pestañas de materias en una F geométrica propia.

| Archivo | Uso |
|---|---|
| `banner.svg` / `banner.png` | Cabecera del README, 1440 × 520 |
| `mark.svg` / `mark.png` | Símbolo cuadrado, 180 × 180 |
| `social-preview.svg` / `social-preview.png` | Vista previa al compartir, 1200 × 630 |

Los SVG son autónomos: el texto está convertido a trazados para conservar el
aspecto en GitHub y en otros visores. Los PNG son conversiones de los mismos
vectores; su metadata registra el origen. No contienen imágenes generadas por IA.

Tipografías: [Libre Baskerville](https://github.com/google/fonts/tree/main/ofl/librebaskerville)
y [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), bajo SIL Open
Font License 1.1. Se incluyen sus avisos de licencia. Los assets originales de
este proyecto se distribuyen bajo MIT, igual que el código.

La dirección visual se preparó con [Impeccable](https://github.com/pbakaus/impeccable).
El sistema completo se documenta en [DESIGN.md](../../DESIGN.md). No utiliza
marcas gráficas de Microsoft ni de una institución educativa.
