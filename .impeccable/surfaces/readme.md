# GitHub README and branding

Purpose: help a university peer understand the local Teams MCP, install it or
ask their agent to do so, and identify its limits within a few minutes.
Mode: Read. Existing GitHub Markdown navigation and code blocks remain native.
Scope: visual assets and repository documentation, no new website or runtime UI.

World: an editorial university bulletin. Warm paper, deep green ink, serif
headline, restrained sans-serif wordmark, one geometric mark linking course tabs.
First surface: banner followed by the concrete purpose, agent-assisted install,
manual install, tools, data handling, USE AT YOUR OWN RISK and contributions.
Signature: continuous spine and tabs, shared by the square mark and banner.
Responsive: the banner scales without cropping; essential instructions remain
live Markdown and never depend on text embedded in the image.
Risk: a wide banner has small secondary lettering on phones. Its meaning is
repeated in the live README title and opening paragraph.

Grounded directions considered: campus wayfinding; exam registers; library
catalogs; scientific journals; university editorial bulletins; campus maps;
student-federation posters. FORM: fifth direction, seed:ded2a0ca75ed6764.
No user aesthetic preference is claimed; routine visual choices were delegated
by the request to prepare the repository with Impeccable branding.

Catalog comparisons: cutting-bench rail declined (unfamiliar metaphor, more
navigation to learn); cathode stack declined (state effects obscure reading);
green capsules declined (promotional hierarchy); magazine program competitive
(editorial clarity, weaker academic identification); daylight section declined
(irrelative spatial metaphor); Miura sheet declined (diagram competes with setup).
Raised the chosen direction through the rail's strict alignment, cathode's
contrast discipline, magazine's reusable mark and Miura's compact-to-full
continuity. Kept no borrowed literal instrument or decorative illustration.

Build: code-led static vectors, self-contained paths, no raster-generated comp.
Verification: rendered assets at native and narrow width; Markdown headings,
relative links, installation commands and public-data exclusions checked.
